# Paste to Markdown Formatter

A simple, offline browser utility that converts pasted rich text directly into formatted Markdown.
This is a lightweight tool designed to grab rich text from your clipboard and translate it into clean Markdown. It uses the Turndown.js library to handle the conversion under the hood.

## How to Use
1. Download the `Paste to Markdown.html` file.
2. Open it in your browser.
3. Paste your formatted text from Word, Google Docs, or a website.
4. Hit the convert button. The tool will interpret the rich text and give you the Markdown equivalent.

## Features
* Mostly offline. It just needs to fetch the Turndown script on the first load.
* Private and secure since everything runs directly in your browser.
* Built-in copy button to speed up your workflow.
